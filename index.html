一、罗马 Roma｜9/19–9/22

9/19｜抵达

20:00左右 抵达罗马 → Roman Holiday Suites 入住 → 简单吃饭、休息。

9/20｜斗兽场 + 市区

11:15 斗兽场预约。结束后午饭，下午按体力顺路走：威尼斯广场 → Campo de' Fiori → Piazza Navona → Pantheon → Trevi。

晚上吃饭后回原酒店取行李，再打车去路演酒店。

9/21｜路演日

上午休息和准备。下午路演；约15:00–16:00结束后，有精神再随便去市区走走，不设必须景点。

9/22｜梵蒂冈 → 佛罗伦萨

退房 → 梵蒂冈附近寄存行李 → 12:00 梵蒂冈博物馆 → 西斯廷礼拜堂，整体约2–2.5小时。

取行李后去 Roma Termini，建议订 17:00以后 的高铁去佛罗伦萨。

交通注意：短距离步行；公交/地铁可 contactless；大行李优先打车；高铁电子票按指定车次上车。

二、佛罗伦萨 Firenze｜9/22–9/25

9/22｜傍晚抵达

到 Firenze Santa Maria Novella → 酒店放行李 → 附近中餐/晚饭 → 休息。

9/23｜City Walk

推荐路线：Duomo → Piazza della Repubblica → 野猪喷泉 → Orsanmichele 外观 → Piazza della Signoria → 乌菲兹外观 → Ponte Vecchio → 阿诺河 → Piazzale Michelangelo。

米开朗基罗广场回程可坐 23路公交，上车 contactless 刷卡即可。

三、比萨 Pisa｜9/24

12:30以后 Firenze SMN → Pisa Centrale，预计14:00左右到。

公交去奇迹广场 → 拍照 → 计划15:30登斜塔 → 广场继续逛 → 17:00–17:30左右回车站 → 18:00以后回佛罗伦萨。

奇迹广场外部免费；主要付费项目是登塔和其他建筑内部。塔票需预约具体时间。

四、威尼斯 Venezia｜9/25–9/27

9/25｜到 Mestre

佛罗伦萨 → Venezia Mestre，酒店在火车站附近，放行李后附近吃饭休息。

9/26｜主岛一日

11:30左右 出门。路线：Santa Lucia → San Polo → Caffè del Doge → Rialto → San Marco → 叹息桥 → Dorsoduro → Bar Ai Artisti → Accademia。

最后从 Accademia 坐 Vaporetto 1号线 回 Ferrovia / Santa Lucia，再返回 Mestre。

交通票：计划使用 AVM Venezia Official App 购买 Venezia Daily Pass。首次真正使用时再激活；乘船/乘车按要求验证。手机满电并带充电宝。

五、米兰 Milano｜9/27–9/29

9/27｜抵达

威尼斯 → Milano Centrale → 车站附近吃饭 → 坐车去酒店，当天不排正式景点。

9/28｜City Walk

酒店 → Duomo → Galleria Vittorio Emanuele II → Piazza della Scala → Brera → Castello Sforzesco → Parco Sempione → Arco della Pace → Chinatown / Via Paolo Sarpi 晚饭。

当天买 ATM 纸质24小时票，首次验证后开始计时。

9/29｜去 Linate

早上退房，优先接入 M4 蓝线 前往 Linate Airport。

全程提醒：高铁按指定车次乘坐；Regionale 纸票留意是否需要验证；有大箱子时不要为了省一点交通费硬拖行李换乘。
