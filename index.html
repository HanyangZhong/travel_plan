一、罗马 Roma｜9/19–9/22

9/19｜抵达

🚕 当日交通
  • 机场/车站 → Roman Holiday Suites：优先打车，晚上到达且有大箱子，省力为主。
  • 当晚不安排公共交通。

20:00左右 抵达罗马 → Roman Holiday Suites 入住 → 简单吃饭、休息。

9/20｜斗兽场 + 市区

🚇 当日交通
  • 酒店 → 斗兽场：优先地铁/公交，看当天导航最顺路线。
  • 斗兽场 → 市区景点：以步行为主，景点集中。
  • 晚饭后 → 原酒店取行李 → 路演酒店：打车，不要拖大箱子换乘。

11:15 罗马斗兽场 Colosseo / Colosseum 预约。结束后午饭，下午按下面顺序慢慢走：

  1. 罗马斗兽场 Colosseo / Colosseum
    已预约 11:15
  2. 威尼斯广场 Piazza Venezia
    顺路看
  3. 鲜花广场 Campo de' Fiori
    下午 City Walk
  4. 纳沃纳广场 Piazza Navona
    顺路可加
  5. 万神殿 Pantheon
    外观/广场为主
  6. 特雷维喷泉 Fontana di Trevi
    傍晚拍照

晚上吃饭后回原酒店取行李，再打车去路演酒店。

9/21｜路演日

🚕 当日交通
  • 上午不出门。
  • 酒店 → 路演地点：地点确认后，优先打车；如果正好在地铁沿线再考虑地铁。
  • 路演结束后若去市区闲逛：短距离步行，远一点就刷卡坐公交/地铁。

上午休息和准备。下午路演；约15:00–16:00结束后，有精神再随便去市区走走，不设必须景点。

9/22｜梵蒂冈 → 佛罗伦萨

🚕 当日交通
  • 酒店退房 → 梵蒂冈寄存点：有行李，建议打车。
  • 梵蒂冈区域：主要步行。
  • 梵蒂冈取行李 → 罗马特米尼火车站 Roma Termini：建议打车，避免带箱子换乘。

退房 → 梵蒂冈附近寄存行李 → 12:00 梵蒂冈博物馆 → 西斯廷礼拜堂，整体约2–2.5小时。

取行李后去 罗马特米尼火车站 Roma Termini，建议订 17:00以后 的高铁去佛罗伦萨。

交通注意：短距离步行；公交/地铁可 contactless；大行李优先打车；高铁电子票按指定车次上车。

二、佛罗伦萨 Firenze｜9/22–9/25

9/22｜傍晚抵达

🚶 当日交通
  • Firenze SMN → 酒店：距离近就步行，如果拖箱子不想走就短程打车。
  • 酒店附近吃饭：步行。

到 佛罗伦萨新圣母玛利亚火车站 Firenze Santa Maria Novella → 酒店放行李 → 附近中餐/晚饭 → 休息。

9/23｜City Walk

🚶 当日交通
  • 白天老城：几乎全部步行。
  • 米开朗基罗广场上山：步行；如果临时觉得累，也可改公交。
  • 广场 → 市中心/酒店：优先坐23 路公交，上车 contactless 刷卡。

推荐步行顺序：

  1. 圣母百花大教堂 Cattedrale di Santa Maria del Fiore / Duomo di Firenze
  2. 共和国广场 Piazza della Repubblica
  3. 野猪喷泉 Fontana del Porcellino / Mercato del Porcellino
  4. 奥尔桑米凯莱教堂 Chiesa di Orsanmichele
    外观顺路看
  5. 领主广场 Piazza della Signoria
  6. 乌菲兹美术馆 Galleria degli Uffizi
    只看外观，不进馆
  7. 老桥 Ponte Vecchio
  8. 阿诺河 Fiume Arno
    沿河慢走
  9. 米开朗基罗广场 Piazzale Michelangelo
    傍晚看全景

米开朗基罗广场回程可坐 23路公交，上车 contactless 刷卡即可。

三、比萨 Pisa｜9/24

🚌 当日交通
  • Pisa Centrale → 奇迹广场：优先公交，节省体力。
  • 奇迹广场内部：步行。
  • 奇迹广场 → Pisa Centrale：有体力就步行；累了就继续坐公交。

12:30以后 从 佛罗伦萨新圣母玛利亚火车站 Firenze Santa Maria Novella (SMN) 出发，预计14:00左右到达 比萨中央火车站 Pisa Centrale。

到达后的顺序：

  1. 比萨中央火车站 Pisa Centrale
  2. 奇迹广场 Piazza dei Miracoli / Piazza del Duomo
  3. 比萨斜塔 Torre di Pisa
    计划预约 15:30 登塔
  4. 比萨大教堂 Cattedrale di Pisa
    外观为主
  5. 圣若望洗礼堂 Battistero di San Giovanni
    外观为主
  6. 比萨中央火车站 Pisa Centrale
    回程

去程优先坐公交到奇迹广场；参观结束后，看体力选择步行或公交回比萨中央火车站。

奇迹广场外部免费；主要付费项目是登塔和其他建筑内部。塔票需预约具体时间。

四、威尼斯 Venezia｜9/25–9/27

9/25｜到 Mestre

🚶 当日交通
  • Mestre 火车站 → 酒店：约 5 分钟，步行最方便。
  • 酒店附近晚饭：步行。

佛罗伦萨 → Venezia Mestre，酒店在火车站附近，放行李后附近吃饭休息。

9/26｜主岛一日

🚆🚤 当日交通
  • Mestre 酒店 → Venezia Mestre：步行。
  • Mestre → Santa Lucia：用当天通票覆盖的区域火车。
  • 主岛白天：以步行为主。
  • Accademia → Ferrovia：坐Vaporetto 1 号线，把这段当作大运河观光。
  • Santa Lucia → Mestre：区域火车返回。

11:30左右 出门。主岛按下面顺序走：

  1. 威尼斯圣露西亚火车站 Venezia Santa Lucia
  2. 圣保罗区 San Polo
  3. 道奇咖啡馆 Caffè del Doge
    第一休息点
  4. 里亚托桥 Ponte di Rialto
  5. 圣马可广场 Piazza San Marco
  6. 圣马可大教堂 Basilica di San Marco
    外观为主
  7. 总督宫 Palazzo Ducale
    外观为主
  8. 叹息桥 Ponte dei Sospiri
  9. 多尔索杜罗区 Dorsoduro
    慢慢散步
  10. 艺术家酒吧 Bar Ai Artisti
    第二休息点
  11. 学院桥 Ponte dell'Accademia
  12. 学院桥码头 Accademia
    坐 Vaporetto 1号线
  13. 火车站码头 Ferrovia
    下船后进 Santa Lucia

最后从 Accademia 坐 Vaporetto 1号线 回 Ferrovia / Santa Lucia，再返回 Mestre。

交通票：计划使用 AVM Venezia Official App 购买 Venezia Daily Pass。首次真正使用时再激活；乘船/乘车按要求验证。手机满电并带充电宝。

五、米兰 Milano｜9/27–9/29

9/27｜抵达

🚇 当日交通
  • 米兰中央火车站 Milano Centrale 附近先吃饭。
  • 中央车站 → 酒店：优先地铁/公交；如果拖行李不方便或已很晚，就打车。

威尼斯 → 米兰中央火车站 Milano Centrale → 车站附近吃饭 → 坐车去酒店，当天不排正式景点。

9/28｜City Walk

🚇 当日交通
  • 酒店 → Duomo：用ATM 纸质 24 小时票，地铁/公交进城。
  • Duomo → Galleria → Scala → Brera → Castello → Parco Sempione → Arco della Pace：主要步行。
  • 走累时可随时坐一两站公交/电车/地铁。
  • 唐人街晚饭后 → 酒店：公共交通返回。

City Walk 顺序：

  1. 米兰大教堂 Duomo di Milano
  2. 埃马努埃莱二世拱廊 Galleria Vittorio Emanuele II
  3. 斯卡拉广场 Piazza della Scala
  4. 布雷拉街区 Brera
    以街区散步为主
  5. 斯福尔扎城堡 Castello Sforzesco
    外观和中庭
  6. 森皮奥内公园 Parco Sempione
    休息
  7. 和平门 Arco della Pace
  8. 米兰唐人街 Chinatown / Via Paolo Sarpi
    晚饭

当天买 ATM 纸质24小时票，首次验证后开始计时。

9/29｜去 Linate

🚇 当日交通
  • 酒店 → 接入 M4 蓝线 → Linate Aeroporto。
  • 如果前一天 24 小时票仍有效可继续用；否则单独买票。

早上退房，优先接入 M4 蓝线 前往 米兰利纳特机场 Aeroporto di Milano Linate。

全程提醒：高铁按指定车次乘坐；Regionale 纸票留意是否需要验证；有大箱子时不要为了省一点交通费硬拖行李换乘。
